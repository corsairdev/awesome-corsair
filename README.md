# Awesome Corsair [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Apps, agents and tools people have built on [Corsair](https://github.com/corsairdev/corsair), each with a link to its code.

Corsair connects apps and agents to 700+ integrations (Gmail, Slack, GitHub, Google Calendar, Linear, HubSpot and the rest) through a TypeScript SDK or one MCP URL. [Lug](https://lug.dev) is the hosted version. Everything listed here was built outside the Corsair team, and every entry says where its use of Corsair can be checked. Many of the first entries came out of ChaiCode's Corsair hackathon in June 2026.
